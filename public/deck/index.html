SUM adds everything. SUMIF adds only the rows matching your condition — essential for department-level reporting.
Module 5 · Logical & Lookup FunctionsLookup Functions — Side-by-Side Reference
VLOOKUP
Find a value in the first column of a table, then return data from another column in the same row.
=VLOOKUP(lookup, table, col, 0)
Use when: cross-referencing two tables by a shared ID
COUNTIF
Count cells in a range that meet a single criterion — text, number, or pattern.
=COUNTIF(range, criteria)
Use when: counting how many rows match a value
SUMIF
Sum values in a range where a corresponding range meets a criterion.
=SUMIF(range, criteria, sum_range)
Use when: totaling by category, region, or status
Quick memory trick
V in VLOOKUP = Vertical (searches down rows). IF in COUNTIF/SUMIF = conditional. These three functions cover 80% of real-world data analysis tasks.
Module 5 · Logical & Lookup FunctionsBonus: The IF Function — Decision Making in Cells
IF checks a condition → returns one value if TRUE, another if FALSE:
EmployeeSales TargetAchievedResult
Raj Kumar$50,000$62,000✓ Bonus
Priya Patel$50,000$48,000✗ No Bonus
Amit Sharma$50,000$55,500✓ Bonus
Anita Rao$50,000$38,200✗ No Bonus
Syntax
=IF(C2>=B2,"Bonus","No Bonus")
Condition · Value if TRUE · Value if FALSE
Can return text, numbers, or even another formula
Nest multiple IFs: =IF(A1>90,"A",IF(A1>75,"B","C"))
Real-world use
Grade assignments, classify customers, flag overdue invoices, calculate tiered bonuses — IF is one of Excel's most powerful tools.

Module 6 · Tables & ChartsWhen to Use Which Chart?
A quick decision guide — choose the right chart for your message
📊
Bar / Column
Best for comparing categories side by side — sales by region, revenue by quarter
→ "Compare values across groups"
🥧
Pie / Donut
Best for showing proportions of a whole — market share, budget breakdown, team composition
→ "Show parts of a whole"
📈
Line
Best for showing trends over time — monthly sales, price history, user growth
→ "Show change over time"
Rule of thumb
If your audience asks "how much?" → Bar chart. "What portion?" → Pie chart. "How has this changed?" → Line chart. Keep charts simple — one message per chart.
